🔍 Troubleshooting Approach

The troubleshooting process involved a systematic approach to identifying faults before carrying out repairs.

Typical Process

1. Visual Inspection
Inspect signal heads, controller equipment, wiring and visible connections.

2. Power Verification
Check the relevant power supply and electrical connections.

3. Equipment Testing
Test relevant components and system functions to identify abnormal operation.

4. Fault Identification
Determine the likely source of the problem based on test results.

5. Repair / Rectification
Carry out the appropriate corrective action.

6. Functional Testing
Test the system after repair to verify correct operation.

7. System Restoration
Confirm that the traffic signal system has returned to normal operation.
